# Resume folder

The **Download Resume** buttons and links point to:

```
/resume/Lokeshwaran_K_Resume.pdf
```

`Lokeshwaran_K_Resume.pdf` currently contains a **placeholder**. Replace it with your final
resume PDF using the **same file name** and the download links will keep working — no code
changes needed.

If you want a different file name, update `resumeUrl` in `src/data/profile.js`.
